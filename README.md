# Solutions to the CS149 Written Assignments
* This repository contains solutions to Stanford's CS149 (Parallel Computing) Written Assignemnts.
* Solutions are in the form of `.xopp` files that can be handled using [`Xournal++`](https://github.com/xournalpp/xournalpp). PDF versions will be available once the assignment is completed and reviewed.
* Work on the assignments is credited to **Nour Nawar** \<nournawar5@gmail.com\> and **Mohamed Taher** \<motaher20004@gmail.com\>.
* For more information about our progress in the course, check the following document: [CS149 notes](https://docs.google.com/document/d/1oCFEGqUTGbfGv2-jbFgzUOsOWBIIq0uGJH9k8rLEya8/edit?usp=sharing)
